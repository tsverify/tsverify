# 7. Name and license

> Status: decided 2026-11-22. Supersedes the working name `tsv` used in docs 1–6.

## Name: `tsverify`

- **Command:** `tsverify` (`tsverify check`, `tsverify test`, `tsverify diff`, `tsverify view`, …).
- **npm:** scoped packages under **`@tsverify`**. Users install `@tsverify/cli`; generated tests import
  `@tsverify/runtime`.
- **Why the `ts` prefix:** the tool should feel native to TypeScript, next to `tsc`, `tsx`, `tsup`, `tsd`.
- **Why scoped:**
  - An unscoped `tsverify` can't be published. npm rejects new names that differ from an existing package only by
    punctuation, and `ts-verify` exists (an abandoned decorator-validation library, last published 2022).
  - Scoped names are exempt from that rule.
  - The scope also keeps the CLI and the runtime together (the pattern of `@biomejs/biome` and `@playwright/test`).
- **Rejected:**
  - `tsv`: collides with tab-separated values.
  - `stateproof`: "proof" overclaims. This is bounded model checking plus conformance, not a formal proof.
  - `statute`, `tsintent`, `tsconform`, `tswitness`: free, but the user preferred staying close to "ts-verify".
- **Kept:** spec files stay `*.behavior.yaml`, which describes their content.
- **To claim:** before the first publish, the npm org `tsverify` and the GitHub org `tsverify`.
- **Before the public release:** a trademark search.

## License: Apache-2.0

- **What it is:** permissive like MIT, plus an explicit patent grant from contributors and patent retaliation.
  Contributions are licensed under the same terms by default.
- **Why it suits us:** it is enterprise-friendly for a CI tool, and it matches TypeScript's own license.
- **Copyright holder:** `Copyright 2026 The tsverify Authors` (`LICENSE` appendix line, `NOTICE`).
- **Generated files:** files tsverify generates in a user's project (e.g. `.tsverify/generated/`) belong to the
  user, and the license places no conditions on them (README "License").
- **Why not copyleft:** `@tsverify/runtime` loads inside users' test processes, and generated tests live in their
  repos. A copyleft license would block adoption.
